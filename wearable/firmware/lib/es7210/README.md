# ES7210 driver

These three files are the microphone driver from Waveshare's official
Arduino example `06_ES7210`:

- `es7210.cpp`
- `es7210.h`
- `audio_hal.h`

Source repository:

https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75C

The driver itself is Espressif code under the MIT license. The copyright
notice is at the top of each file. It is included here so this project
builds without a separate download and so the register setup matches the
board demo instead of a guessed one.
